# AWS source baseline and operational routine

## Source of truth for this synchronization

This change recovers application source and configuration from the existing AWS
Lambda artifacts. It does not deploy new code or issue any document.

| Function | Deployment modified (UTC) | Role |
| --- | --- | --- |
| mtm-hbl-original-worker-dev | 2026-08-28 15:41:22 | Queued draft/original issuance |
| mtm-hbl-original-webhook-dev | 2026-08-28 15:40:09 | Authenticated issuance webhook |
| mtm-hbl-verification-dev | 2026-06-12 02:19:49 | Public verification and terms |

The worker and webhook contain identical application/configuration files. The
verification service is a separate application, taken from its own deployment.
`aws-source-baseline.json` records Lambda artifact hashes and SHA-256 hashes for
each recovered source/config/terms file. Validate the snapshot offline with:

```bash
python3 tools/verify_aws_source_baseline.py
python3 -m pytest tests -q
```

The baseline intentionally excludes installed dependencies, bytecode, live
environment values, credentials, signatures, shipment documents, and operational
receipts. It is a source baseline, not a reproducible binary Lambda build. The
repository's original tests, tools, and infrastructure files were retained;
infrastructure parity has not been established by recovering the runtime source.
`PyJWT[crypto]` is required by the recovered manager authentication module.

## Normal issuance

`aws_handlers.original_issuer` accepts an authenticated webhook, queues work, and
records job state. The worker calls `generate_hbl_from_clickup` with:

- `attach_to_clickup=True`
- `post_comment=True`
- `prevent_original_overwrite=True`

After generation/registration, it uploads to the configured HBL Original custom
field using the workspace custom-field attachment endpoint, verifies the field,
updates status to the configured `READY FOR ORIGINAL`, and posts an assigned
comment. General task attachments are not equivalent to a custom-field upload.

The comment is generated by `_comment_text` and assigned to the first task
assignee by `_comment_assignee_id`:

```text
HBL package issued for {hbl_number}.
Package ID: {package_id}
Verification: {first_verification_url}
```

The verification page displays the PDF SHA-256. The comment remains unresolved
for its assignee. Do not regenerate an HBL to repair a missing attachment, status,
or comment; reconcile the already-issued package and verify the repaired state.
The generic local CLI exposes flags rather than automatically applying all worker
settings. Use the worker entry point for its complete normal-issuance behavior.

## Manager reissue source versus deployed entry points

The recovered `aws_handlers.hbl_admin` source includes Entra authentication,
preview and confirmation, replacement issuance, prior-record voiding, and an
additional assigned audit comment. It issues/uploads the replacement first, then
voids old records and posts the audit comment. It deliberately disables the
normal original-overwrite guard for that controlled replacement.

At inspection, the source was bundled in the issuer package, but no Lambda
handler or HBL API Gateway route exposing the admin flow was found in the inspected
us-east-1 account. A configured admin URL does not establish that this code is
reachable. This sync does not activate a manager portal.

The recovered manager source records a manager-identity reason, not a custom
customer-supplied reason. It uses sequential external operations and the existing
per-record void helper; it is not the local recovery's atomic old/new transaction.
Preserve these distinctions when assessing readiness. Source synchronization does
not add a new resumable reissue workflow or establish end-to-end production safety.

## Keeping source aligned

Future runtime changes should be reviewed in GitHub, tested, and deployed from an
identified revision. Update the baseline only after verifying the target artifact.
Never blindly overwrite repository work with a deployment or commit secret/runtime
assets. Keep shipment-specific recovery scripts outside the application repository.
